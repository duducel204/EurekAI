# Hipóteses

**Estado atual:** área ativa para interpretações ainda não canonizadas como conhecimento ou decisão.

## Função

`hipoteses/` registra interpretações, apostas explicativas, possíveis relações e propostas ainda pendentes de validação.

## Estado pós-GOAL-010

Novas hipóteses devem surgir principalmente de pipelines, investigações, auditorias e evolução do produto.

## Regra semântica

Hipótese não é fato. Hipótese não é decisão. Hipótese pode orientar investigação, mas não deve ser apresentada como conhecimento canônico até validação suficiente.
