## Regra semântica

Esta pasta preserva evidência de execução histórica, mas não substitui:

- `ESTADO.md` para estado atual;
- `codex/goals/ROADMAP-GOALS.md` para roadmap;
- `execucoes/` para relatórios multiagente recentes.
