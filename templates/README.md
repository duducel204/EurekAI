# Templates

**Estado atual:** área para formatos reutilizáveis validados.

## Função

`templates/` guarda estruturas reutilizáveis para relatórios, unidades, inventários, auditorias ou outros artefatos recorrentes.

## Estado pós-GOAL-010

Templates futuros devem refletir a operação por pipelines permanentes e os contratos atuais de conhecimento, ingestão e execução.

## Regra semântica

Template não é conteúdo validado. Ele define forma, não prova, decisão ou conhecimento.
