# Adaptador Cloud Code / Gemini Code Assist

Use o ambiente de desenvolvimento Google para colaborar no mesmo EurekAI, não para criar uma variante do projeto.

## Prioridades
Leia `/AGENTS.md` e o contexto do workspace. Em tarefas Google Cloud, diferencie: serviço disponível, serviço configurado, serviço efetivamente usado e serviço canonizado na arquitetura.

## Infraestrutura
Configurações locais, credenciais e recursos de projeto Google Cloud não devem ser documentados como fatos do EurekAI sem evidência e necessidade. Mudanças de infraestrutura devem registrar finalidade, escopo, custo/risco relevante e forma de validação.

## Handoff
Toda conclusão que outro agente precise reutilizar deve voltar ao GitHub em estrutura canônica e com procedência suficiente para ser auditada.
