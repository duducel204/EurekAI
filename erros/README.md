# Erros

**Estado atual:** área reservada para erros, falhas e correções aprendidas.

## Função

`erros/` registra problemas observados, diagnósticos, correções e aprendizados.

Erro não deve ser apagado para parecer coerente. Ele deve ser preservado com contexto, porque pode gerar aprendizado reutilizável.

## Estado pós-GOAL-010

Pipelines e agentes devem registrar erros relevantes aqui quando eles tiverem valor de aprendizado ou risco de recorrência.

## Regra semântica

Não tratar ausência de evidência como erro. Não tratar divergência de hipótese como falha. Erro exige comportamento, decisão ou resultado incompatível com o esperado.
